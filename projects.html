DeenBit Projects

Your DeenBit is fully programmable. Start with one of these project ideas, learn how the code works, then change it and create something of your own.

Learn by building

Projects can be programmed using Microsoft MakeCode with simple drag-and-drop blocks, or you can go further and write code yourself. No programming experience is needed to get started.

📿

Build a Thikr Counter

Turn Button A into a digital counter. Display your count and add a celebration when you reach 33, 99 or 100.

Level: Beginner
Learn: Buttons · variables · LED display
🧭

Build a Qibla Compass

Use the micro:bit compass to explore direction and program an arrow that helps point toward a configured Qibla direction.

Level: Intermediate
Learn: Compass · direction · conditions
👏

Clap Night Light

Use the microphone to detect sound and switch your night light on and off with a clap.

Level: Beginner
Learn: Microphone · events · outputs
🌡️

Temperature Display

Read the micro:bit temperature and display it when Button B is pressed. Then add your own hot and cold icons.

Level: Beginner
Learn: Sensors · values · displays
🌙

Ramadan Lantern

Connect external LEDs and create your own programmable Ramadan lantern with patterns, animations and button controls.

Level: Beginner–Intermediate
Learn: GPIO · LEDs · loops
✨

Islamic LED Art

Design crescent moons, stars, hearts, letters and animations using the micro:bit's 5×5 LED display.

Level: Beginner
Learn: LEDs · patterns · animation
🎲

Islamic Quiz Game

Create your own question-and-answer game using Buttons A and B, keep score and challenge family or friends.

Level: Intermediate
Learn: Logic · input · variables
🤝

Good Deeds Counter

Create a daily counter for good deeds and fill the LED display as you work toward your own goal.

Level: Beginner
Learn: Counters · goals · display
🛠️

Create Your Own Project

Change what the buttons do, use the microphone, compass, accelerometer and pins, or connect your own electronics.

Level: Your choice
Learn: Experimentation · coding · creativity

💻 Ready to start coding?

Plug your DeenBit into your computer and use Microsoft MakeCode to build programs with blocks. Experiment freely — you can always load the original DeenBit program again later.
