Growing Kids Code Clubs

Learning to code is even better together. DeenBit aims to help communities start and grow Code Clubs where learners, volunteers and mentors explore programming, electronics and creative problem-solving.

From a first micro:bit project to a shared community workshop, the goal is to make hands-on technology learning more accessible, collaborative and fun.

🎁 micro:bit Club Kits Available

Thanks to a generous donation received by Coder:LevelUp, micro:bit Club Kits are available to support community Code Clubs.

These kits will be shared with Code Clubs following a simple set of steps and guidelines.
